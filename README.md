# 动态课程表 📅

一个**纯前端、无服务器**的移动端网页应用（PWA）：拍照导入课表、课前定时提醒、课后拍照/语音记笔记、晚间自动总结、周末生成复习计划。数据全部保存在手机本地浏览器中。

## 功能

| 功能 | 说明 |
|---|---|
| 📷 课表导入 | 拍照/相册识别课表照片（本地 OCR 或大模型），或粘贴文本、手动录入；支持周次（1-16周）、单双周、连堂课、每课不同教室；识别结果逐条核对后保存 |
| ⏰ 定时提醒 | 晨间简报（今日课程+教室）；上午/下午/晚上时段首节课前 40 分钟提醒（可改为每节课提醒，提前量可调）；下课后提醒记笔记；晚间提醒生成总结；周六提醒复习计划 |
| ✏️ 课后笔记 | 拍课本/板书照片（自动压缩存储+OCR 转文字）、语音听写（浏览器语音识别）、手动输入；自动关联当前/刚下课的课程 |
| 🌙 晚间总结 | 按课程聚合当日笔记，抽取要点与待办/疑问，生成"明日准备"清单（教室、时间、要带的东西）；支持大模型增强 |
| 📚 周末复习 | 根据本周各课笔记量、疑问数、久未复习程度排优先级，生成周六/周日复习时间块计划 |
| 💾 数据安全 | IndexedDB 本地存储，JSON 一键导出/导入备份；支持深色模式；可离线使用 |

## 在手机上使用

**方式一：局域网访问（最快）**
```bash
# 电脑上进入本目录，启动服务
python3 -m http.server 8080
# 手机连接同一 WiFi，浏览器访问
# http://<电脑局域网IP>:8080
```

**方式二：免费静态托管（推荐长期使用）**
部署到 GitHub Pages / Vercel / Netlify 任一静态托管（整个目录直接上传即可），手机通过 https 地址访问。

**建议**：用手机浏览器菜单中的「添加到主屏幕」，即可像 App 一样全屏使用并离线可用。

> ⚠️ 注意：直接用 `file://` 双击打开无法使用（相机、语音、存储等需要 http/https 环境）。

## 首次使用

1. **设置 → 学期**：填写第一周周一的日期和总周数（用于计算第几周、单双周）
2. **课表 → 导入课表**：拍一张课表照片（截图更佳），核对识别结果后保存；也可手动添加
3. **设置 → 提醒**：点击「开启系统通知」授权
4. 开始使用：上完课在「记录」页拍照/说几句，晚上在「总结」页生成今日总结

## AI 增强（可选，推荐）

默认使用完全免费的本地方案（Tesseract.js 离线 OCR + 浏览器语音识别 + 本地算法总结）。在 **设置 → AI 增强** 中配置任意 OpenAI 兼容接口后，以下能力由大模型完成，质量显著提升：

- 课表照片 → 结构化课表（准确率高得多）
- 笔记照片 → 文字
- 今日总结 / 周末复习计划

配置示例（DeepSeek）：
- 接口地址：`https://api.deepseek.com/v1`
- API Key：你的 key（仅保存在本机 localStorage）
- 文本模型：`deepseek-chat`
- 视觉模型：DeepSeek 暂无视觉模型，可换智谱 `https://open.bigmodel.cn/api/paas/v4` + `glm-4v-flash`（免费）

## 已知限制（诚实说明）

- **后台通知**：网页应用只有在打开或后台驻留时才能弹出提醒，完全杀掉浏览器后无法推送（平台限制）。添加到主屏幕并保持后台可大幅改善；每天首次打开必见当日简报。
- **语音听写**：依赖浏览器能力，Android Chrome 支持最好；不支持的浏览器会自动隐藏语音按钮。
- **本地 OCR 准确率**：Tesseract 对中文照片的识别率一般（清晰截图约 70-85%），因此导入后必须核对；配置大模型后基本不需要操心。

## 开发与测试

```bash
# 纯函数单元测试（解析/总结/课表模型）
node tests/run-tests.mjs

# 本地起服务
python3 -m http.server 8080
```

技术栈：原生 ES Modules + IndexedDB + Service Worker（PWA），无构建步骤、无依赖、无后端。

## 目录结构

```
index.html          # 单页应用壳
manifest.json       # PWA 清单
sw.js               # Service Worker（离线缓存 + 通知）
css/app.css         # 移动优先样式（含深色模式）
js/
  main.js           # 入口：路由、SW 注册、提醒引擎
  settings.js       # 设置（节次时间/提醒/AI 配置）
  db.js             # IndexedDB 封装
  data.js           # 数据访问层
  model.js          # 课表模型（周次/单双周/当前课）
  parser.js         # 课表解析（文本/OCR 表格/AI JSON）
  ocr.js            # Tesseract.js + 图片预处理
  ai.js             # OpenAI 兼容接口适配
  speech.js         # 语音听写
  reminders.js      # 提醒引擎
  summarize.js      # 本地抽取式总结
  review.js         # 周末复习计划
  ui.js             # 共享组件（sheet/toast/markdown/图标）
  views/            # 5 个页面视图
tests/run-tests.mjs # 单元测试
```
